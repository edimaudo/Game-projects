Game Design Requirements

Front End
- About page
 - It should have what the game is about and how to play the game

- Game Setting page
 - Will have to ability to change the theme (dark or light mode)
 - Will show the top score & how long it took to achieve the score

- Game Page
  - There should be a font that is shown and above it should be the question what font is this
  - There should be two answers.  They cannot be the same font name.  Also the font shown should match one of the answers generated
  - The question and the answers should be centered on the screen
  - If the user exits the app the game should end and no score collected
  - When the game starts there should be a timer that starts going and counts every second until the game ends.  If the user exits the app the timer should stop
  - There should be a question counter showing 0/15 when starting, it should update by 1 when the user gets the question right, if the user gets the question wrong it should not update
  - When the user has answered all the questions, the timer should stop and the total score and total time in minutes should be shown in a banner.  If the top score in the current game is higher than the current top score then the top score and time should be updated
  - When the game is first played the top score should be zero.  After the first game play the top score should be updated with the one after the game
